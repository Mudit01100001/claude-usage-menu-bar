## 1. Portfolio Website Case Study (Technical & Concise)

*Copy and paste this structured case study onto your portfolio website.*

### Project Overview
A native macOS status bar utility designed to track rolling Claude.ai session and weekly limits in real-time. Built entirely in Swift (SwiftUI + AppKit) with a zero-dependency build system.

* **Role:** Solo Creator (Design & Native macOS Engineering)
* **Tech Stack:** Swift, SwiftUI, AppKit, macOS SDK, Security/Keychain APIs, URLSession, Combine
* **Repository:** [github.com/Mudit01100001/claude-usage-menu-bar](https://github.com/Mudit01100001/claude-usage-menu-bar)

### The Problem
Power users of Claude.ai (Web) and Claude Code (CLI) frequently hit rolling utilization limits (e.g., the 5-hour and 7-day windows) in the middle of deep work. Checking limits manually is cumbersome, and hitting a rate limit abruptly interrupts developer flow. 

### The Solution
A lightweight background menu bar app (`LSUIElement`) that dynamically polls Anthropic’s API endpoints, parses rolling limits, and displays real-time utilization indicators. 

### Key Technical Challenges & Implementations
1. **Zero-Bloat Native Compilation:** Instead of utilizing heavy Xcode projects, I designed a custom command-line compilation pipeline using `swiftc` and packaged it directly into a standard `.app` bundle structure in under 2 seconds.
2. **Secure Credentials at-Rest:** Designed a native integration with the **macOS Keychain** using secure generic password entries (`kSecClassGenericPassword`). Users' sensitive session keys are stored with hardware-backed AES encryption (Secure Enclave).
3. **Resilient CLI Token Extraction:** Built a subprocess-based scanning pipeline that queries the system keychain for tokens generated by `claude login`, utilizing secure argument vectors to prevent injection.
4. **Adaptive UX/UI:** Leveraged AppKit's `NSStatusItem` and SwiftUI's `HSplitView` to build a resizable sidebar settings panel alongside custom AppKit-drawn progress views in the dropdown menu.
